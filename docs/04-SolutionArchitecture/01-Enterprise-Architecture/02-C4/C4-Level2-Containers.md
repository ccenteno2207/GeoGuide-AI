# C4 Nivel 2
- Flutter App
- Backend Spring Boot
- PostgreSQL + PostGIS
- Redis
- MinIO
- Nginx

La Flutter App aloja la presentación y adaptadores del dispositivo; el backend aloja
los casos de uso independientes del canal. STT/TTS se integran mediante adaptadores
sustituibles cuando se habiliten. Route Discovery, proximidad, ranking y fichas
factuales funcionan sin LLM.
