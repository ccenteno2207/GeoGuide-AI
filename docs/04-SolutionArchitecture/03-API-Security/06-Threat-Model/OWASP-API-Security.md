# OWASP API Security – Aplicación al proyecto

Controles mínimos:
- Autorización por objeto.
- Autenticación robusta.
- Protección contra consumo excesivo.
- Validación de propiedades.
- Autorización por función.
- Protección de flujos sensibles.
- Mitigación SSRF.
- Configuración segura.
- Inventario/versionado de APIs.
- Evaluación de APIs externas.

Toda nueva API debe pasar revisión de seguridad antes de liberarse.
