# Protección de Datos

Clasificación:
- Pública: POIs, categorías, descripciones.
- Interna: métricas técnicas.
- Confidencial: credenciales, tokens.
- Personal: perfil, favoritos, historial si se habilita.

Reglas:
- Minimizar datos personales.
- No almacenar ubicación histórica por defecto.
- Consentimiento cuando corresponda.
- Cifrado en tránsito.
- Backups protegidos.
- Política de retención documentada.
