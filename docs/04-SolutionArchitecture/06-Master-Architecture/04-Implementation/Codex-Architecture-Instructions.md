# Instrucciones para Codex

Antes de modificar código:
1. leer README y documentación de arquitectura;
2. identificar el módulo afectado;
3. verificar ADR;
4. no introducir servicios SaaS propietarios sin aprobación;
5. mantener stack open source del piloto;
6. ejecutar pruebas;
7. actualizar OpenAPI si cambia un endpoint;
8. actualizar migraciones si cambia datos;
9. proponer ADR para decisiones irreversibles o de alto impacto.

No convertir el MVP en microservicios salvo una decisión arquitectónica explícita.
