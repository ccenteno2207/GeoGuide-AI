# Gobierno de Arquitectura

## Cambios
Toda decisión estructural debe registrarse como ADR.

## Revisión mínima
- impacto funcional;
- seguridad;
- datos;
- licencias;
- operación;
- costo;
- pruebas;
- reversibilidad.

## Branching documental
Los cambios de arquitectura se revisan mediante Pull Request.

## Definition of Done documental
Una funcionalidad que cambia contratos, datos o despliegue no está completa hasta que
la documentación afectada también se actualiza.
