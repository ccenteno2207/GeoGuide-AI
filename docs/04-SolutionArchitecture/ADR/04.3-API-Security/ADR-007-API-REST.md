# ADR-007 – REST para el MVP

Estado: Aceptado

Decisión:
Utilizar REST/JSON sobre HTTPS.

Motivo:
Simplicidad, soporte nativo en Flutter/Spring, facilidad de operación y documentación.

Alternativas:
GraphQL y gRPC.

Consecuencia:
Las APIs públicas deberán mantener contratos estables y versionados.
