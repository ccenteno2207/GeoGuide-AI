# Accesibilidad Mobile

Objetivo: buenas prácticas equivalentes a WCAG 2.2 AA donde sean aplicables.

- Semantic labels.
- Targets táctiles suficientes.
- Soporte de text scaling.
- Contraste.
- No usar solo color.
- Lectores de pantalla.
- Orden de foco.
- Motion reducido.
- Iconos acompañados de significado accesible.

## Mapas
Los POIs importantes deben ser accesibles también mediante listas/tarjetas, no únicamente
a través de elementos visuales sobre el mapa.
