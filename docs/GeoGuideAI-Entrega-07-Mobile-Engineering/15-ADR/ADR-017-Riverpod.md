# ADR-017 – Riverpod para estado

**Estado:** Recomendado / sujeto a validación en bootstrap.

## Decisión
Riverpod será la opción por defecto para gestión de estado.

## Razones
- testable;
- adecuado para async;
- composición;
- baja dependencia del árbol visual.

Si durante bootstrap aparece una incompatibilidad relevante, registrar ADR antes de cambiar.
