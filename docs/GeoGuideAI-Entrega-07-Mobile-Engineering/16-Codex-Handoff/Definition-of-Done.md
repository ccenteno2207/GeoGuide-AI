# Definition of Done Mobile

- [ ] `dart format` aplicado.
- [ ] `flutter analyze` sin errores.
- [ ] `flutter test` pasa.
- [ ] arquitectura por features respetada.
- [ ] UI coincide con UX baseline.
- [ ] loading/empty/error implementados.
- [ ] permisos manejados.
- [ ] no hay secretos hardcoded.
- [ ] no hay tokens en logs.
- [ ] atribución de mapa visible.
- [ ] funcionalidad probada en dispositivo/emulador.
- [ ] documentación actualizada.
- [ ] cambios arquitectónicos tienen ADR.
