# Estrategia de Mapas

## Datos
OpenStreetMap.

## Cliente
Se evaluarán:
- flutter_map;
- MapLibre Flutter.

Para el MVP se priorizará:
- licencia abierta;
- facilidad de integración;
- soporte de markers;
- polylines;
- clustering;
- control de tile source;
- posibilidad futura de mapas offline.

## Atribución
La atribución exigida por OpenStreetMap debe mostrarse correctamente.

## Tiles
No asumir que los servidores públicos de tiles de OSM son adecuados para producción
a gran escala. El piloto puede usar una configuración permitida; la evolución debe
considerar infraestructura propia o un proveedor compatible con las políticas/licencias.
