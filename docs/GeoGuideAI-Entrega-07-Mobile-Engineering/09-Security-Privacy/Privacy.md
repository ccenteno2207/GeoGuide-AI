# Privacidad

## Principios
- minimizar datos;
- consentimiento contextual;
- transparencia;
- ubicación solo cuando aporta funcionalidad.

## Ubicación
GeoGuide AI necesita ubicación para mostrar posición y apoyar el viaje.
No requiere almacenar un historial permanente para el MVP.

## Permisos
Solicitar cada permiso cerca del momento en que se usa, explicando para qué sirve.
