# Historias de Usuario

- Como viajero quiero descubrir POIs confiables cerca de mi ubicación para entender
  qué vale la pena explorar a mi alrededor.
- Como viajero quiero descubrir POIs durante mi ruta para decidir cuáles podrían valer
  la pena; en una evolución posterior quiero conocer el desvío y tiempo adicional
  estimados para tomar una decisión mejor informada.
- Como usuario quiero distinguir hechos con fuente de resúmenes generados para evaluar
  la confiabilidad de una ficha.
- Como conductor quiero recibir avisos y respuestas de voz breves sin manipular el
  teléfono.
