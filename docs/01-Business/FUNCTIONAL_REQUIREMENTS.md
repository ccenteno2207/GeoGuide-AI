# Requisitos Funcionales

RF1 Obtener o usar la ubicación actual con permiso del usuario.
RF2 Planificar o recibir una ruta entre origen y destino.
RF3 Descubrir POIs por proximidad a la ubicación y dentro de un corredor de ruta.
RF4 Filtrar, ordenar y explicar resultados con reglas deterministas.
RF5 Mostrar fichas de POI separando hechos y fuentes de contenido generado.
RF6 Ofrecer Driving/Travel Mode con avisos breves y mínima interacción visual.
RF7 Permitir que UI, voz y clientes futuros invoquen los mismos casos de uso.
RF8 Habilitar el flujo de voz STT → intención contextual → servicios GeoGuide → TTS
sin hacer obligatorio un LLM para las funciones centrales.
