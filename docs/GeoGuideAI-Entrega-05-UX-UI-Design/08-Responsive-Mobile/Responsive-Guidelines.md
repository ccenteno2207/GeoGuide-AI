# Responsive Mobile

## Breakpoints conceptuales
El diseño debe adaptarse por espacio disponible, no por modelos concretos de teléfono.

## Orientación
- Portrait: experiencia principal.
- Landscape: mapa ampliado y controles mínimos.
- Tablet: panel lateral opcional.

## Safe areas
Respetar notch, barras del sistema y áreas gestuales.
