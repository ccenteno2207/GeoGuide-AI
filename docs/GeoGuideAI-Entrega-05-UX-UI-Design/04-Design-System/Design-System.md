# Design System

## Filosofía
Sistema visual sobrio, natural, legible y orientado a mapas.

## Tokens semánticos
No codificar colores directamente en widgets. Definir tokens:
- color.primary
- color.secondary
- color.surface
- color.background
- color.text.primary
- color.text.secondary
- color.success
- color.warning
- color.error
- color.route
- color.poi.nature
- color.poi.culture
- color.poi.services

## Tipografía
Usar una familia open source con alta legibilidad (p. ej. Inter o Noto Sans) y
mantener escala tipográfica centralizada.

## Espaciado
Base 4/8 px.

## Componentes
- AppBar
- SearchField
- RouteInput
- PrimaryButton
- SecondaryButton
- FilterChip
- PoiMarker
- PoiPreviewCard
- PoiDetailSheet
- RouteSummaryCard
- StatusBanner
- LoadingSkeleton
- EmptyState
- ErrorState

## Iconografía
Utilizar iconografía open source y consistente.
