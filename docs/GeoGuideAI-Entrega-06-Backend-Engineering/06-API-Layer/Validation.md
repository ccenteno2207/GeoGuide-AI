# Validación

## API
Bean Validation:
- @NotNull
- @NotBlank
- @Size
- @Min/@Max
- validaciones personalizadas cuando corresponda.

## Coordenadas
Latitude: -90 a 90.
Longitude: -180 a 180.

## Parámetros espaciales
Definir límites máximos para:
- radiusMeters;
- corridorMeters;
- maxDetourMeters;
- page size.

Los límites exactos serán configuración/documentación, no valores duplicados.
