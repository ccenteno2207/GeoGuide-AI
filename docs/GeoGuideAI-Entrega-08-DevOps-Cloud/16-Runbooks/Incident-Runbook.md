# Runbook – Incidente

1. identificar impacto;
2. preservar logs/evidencia;
3. revisar host/containers;
4. revisar backend;
5. revisar DB;
6. revisar routing;
7. revisar disco/RAM;
8. aplicar mitigación;
9. validar servicio;
10. documentar causa y acciones.

No eliminar datos/logs para 'resolver' sin entender el impacto.
