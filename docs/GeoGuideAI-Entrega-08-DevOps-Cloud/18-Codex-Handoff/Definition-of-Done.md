# Definition of Done DevOps

- [ ] configuración versionada;
- [ ] secretos fuera de Git;
- [ ] `docker compose config` válido;
- [ ] contenedores healthy;
- [ ] puertos internos no públicos;
- [ ] CI verde;
- [ ] scans ejecutados;
- [ ] imágenes trazables;
- [ ] HTTPS en ambiente público;
- [ ] backup ejecutado;
- [ ] restore probado;
- [ ] health/smoke tests;
- [ ] rollback documentado;
- [ ] documentación actualizada.
