# Evaluación de Modelos

Dataset de evaluación propio del dominio:
- turismo;
- historia;
- geografía;
- español;
- nombres locales;
- preguntas sin evidencia;
- traducción/resumen.

Criterios:
- factualidad;
- groundedness;
- utilidad;
- latencia;
- consumo de RAM/CPU/GPU;
- licencia;
- tamaño;
- soporte multilingüe.

No seleccionar modelo solo por benchmark genérico.
