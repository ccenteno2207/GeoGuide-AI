# Normalización

## Campos
- nombre;
- categoría;
- lat/lon;
- dirección;
- horarios;
- precios;
- teléfonos;
- URLs;
- idioma;
- descripción.

## Coordenadas
SRID canónico EPSG:4326.

## Texto
- UTF-8;
- preservar caracteres originales;
- detectar idioma cuando sea útil;
- no eliminar nombres indígenas/locales.

## Categorías
Mapear taxonomías externas a la taxonomía interna sin destruir el valor original.
