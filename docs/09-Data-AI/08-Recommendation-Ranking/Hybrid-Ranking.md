# Ranking Híbrido

El Route Discovery Engine mantiene el ranking base geoespacial.

## Factores deterministas
- distancia a ruta;
- desvío;
- progreso;
- categoría;
- calidad del POI;
- estado operativo.

## Personalización futura
- preferencias explícitas;
- favoritos;
- categorías;
- feedback.

## AI/ML futuro
Puede aportar una señal adicional, nunca reemplazar restricciones geográficas,
seguridad o disponibilidad factual.

## Explicabilidad
Guardar reason codes:
- NEAR_ROUTE
- LOW_DETOUR
- PREFERRED_CATEGORY
- HIGH_DATA_QUALITY
- CULTURAL_INTEREST
