# Especificación – Mapa Principal

## Elementos
- mapa a pantalla completa;
- posición actual;
- controles de origen/destino;
- acción calcular ruta;
- botón recentrar;
- filtros;
- POI markers;
- bottom sheet contextual.

## Comportamiento
Al tocar un marcador se abre una tarjeta resumida sin abandonar el mapa.
El detalle completo se abre mediante acción explícita.

## Rendimiento
Aplicar clustering cuando la densidad de marcadores lo requiera.
