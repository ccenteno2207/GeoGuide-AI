# Modo Viaje / Conducción

## Objetivo
Minimizar distracciones.

## Reglas
- texto grande;
- pocas acciones;
- evitar formularios;
- información prioritaria: próximo POI, distancia y tipo;
- audio breve y prioritario cuando voz esté habilitada;
- no mostrar textos históricos extensos mientras el vehículo está en movimiento;
- acciones complejas deben requerir que el usuario esté detenido o salir del modo conducción.

GeoGuide AI no debe incentivar interacción manual prolongada durante la conducción.
La voz sigue el flujo STT → intención contextual → servicios GeoGuide → TTS y presenta
los mismos hechos que la UI. No se presenta como conversación abierta ni sustituye las
fichas y fuentes confiables.
