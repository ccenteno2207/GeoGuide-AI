# Personas y Journey

## Persona primaria: viajero por carretera
Necesita planificar recorridos interprovinciales y descubrir lugares sin investigar
manualmente cada localidad.

## Journey MVP
Planificar → revisar ruta → elegir categorías → descubrir POIs → iniciar recorrido →
recibir aviso → consultar ficha cuando sea seguro → marcar favorito/visitado.

## Pain points
- Lugares interesantes invisibles desde la carretera.
- Información dispersa.
- Dificultad para estimar desvíos.
- Cobertura móvil irregular.
