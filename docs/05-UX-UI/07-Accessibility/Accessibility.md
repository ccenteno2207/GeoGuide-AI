# Accesibilidad

Objetivo: alinearse con WCAG 2.2 AA donde aplique a la experiencia móvil.

- Contraste suficiente.
- Escalado de texto.
- Targets táctiles adecuados.
- Labels semánticos.
- Compatibilidad con lectores de pantalla.
- No comunicar estados solo mediante color.
- Orden lógico de foco.
- Texto alternativo en imágenes informativas.
- Reducir animaciones si el sistema lo solicita.
