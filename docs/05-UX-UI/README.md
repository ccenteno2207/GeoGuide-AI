# GeoGuide AI – Entrega 05 – UX/UI Design
Baseline UX/UI del MVP móvil de GeoGuide AI.

## Objetivo
Diseñar una experiencia centrada en el viajero que permita:
1. ver su posición en el mapa;
2. elegir origen y destino;
3. calcular una ruta;
4. descubrir POIs a lo largo del recorrido;
5. filtrar lugares;
6. consultar fichas;
7. recibir información útil sin distraer durante la conducción.

## Principio central
La interfaz debe priorizar seguridad, simplicidad y lectura rápida. Las interacciones
complejas se realizan con el vehículo detenido. Durante el desplazamiento se reduce
la carga visual y se favorecen avisos breves y audio.
