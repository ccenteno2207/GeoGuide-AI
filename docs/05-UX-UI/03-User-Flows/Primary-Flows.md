# Flujos Principales

## UF-01 Planificar ruta
Inicio → origen → destino → calcular → visualizar ruta → explorar POIs.

## UF-02 Descubrir lugar
Ruta → filtro categorías → marcador → tarjeta rápida → detalle.

## UF-02A Descubrir alrededor
Ubicación autorizada → POIs cercanos → filtro → tarjeta rápida → detalle.

## UF-03 Viaje en curso
Iniciar viaje → ubicación actual → próximos POIs → aviso breve → continuar.

## UF-03A Consultar por voz
Activar voz → STT → intención con contexto de viaje → servicio GeoGuide → respuesta
TTS breve. El detalle extenso se reserva para cuando el usuario esté detenido.

## UF-04 Favorito
Detalle POI → guardar → confirmación → favoritos.

## UF-05 Sin conectividad
Detectar offline → usar datos disponibles → informar limitaciones → reintentar sincronización.
