# Categorías visuales de POI
- Naturaleza: catarata, laguna, montaña, bosque, playa.
- Cultura: museo, sitio arqueológico, monumento, iglesia histórica.
- Paisaje: mirador.
- Servicios: combustible, salud, alimentación, hospedaje.
- Otros: categoría genérica.

No depender únicamente del color: cada categoría debe combinar icono + etiqueta.
