# Capas del Mapa

Orden recomendado:
1. tiles/base map;
2. route polyline;
3. corridor opcional de depuración;
4. POI markers;
5. selected POI;
6. current location;
7. overlays UI.

## Marcadores
Cada POI debe tener:
- categoría mediante icono;
- estado seleccionado;
- clustering cuando corresponda.

No depender solo del color.
