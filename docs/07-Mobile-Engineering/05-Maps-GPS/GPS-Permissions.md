# GPS y Permisos

## Flujo
1. verificar servicio de ubicación;
2. verificar permiso;
3. explicar necesidad;
4. solicitar permiso;
5. manejar denegación;
6. manejar denegación permanente;
7. obtener ubicación;
8. suscribirse a cambios solo cuando sea necesario.

## Privacidad
No persistir historial de ubicación por defecto.

## Consumo de batería
El tracking continuo debe activarse únicamente durante viaje/modo conducción o cuando
una función realmente lo requiera.

## Precisión
No solicitar máxima precisión permanentemente si no aporta valor.
