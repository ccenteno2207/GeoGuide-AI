# Entorno de Desarrollo

## Requisitos
- Flutter estable.
- Dart incluido.
- Android Studio SDK o Android SDK CLI.
- VS Code.
- Flutter/Dart extensions.
- dispositivo Android o emulador.

## Verificación
```bash
flutter doctor
flutter --version
dart --version
```

## Configuración
La URL del backend debe provenir de configuración/flavor, no hardcoded.

Ejemplo conceptual:
`API_BASE_URL=http://...`

## Dispositivo físico
Para un piloto de rutas se recomienda validar pronto en un teléfono Android real.
