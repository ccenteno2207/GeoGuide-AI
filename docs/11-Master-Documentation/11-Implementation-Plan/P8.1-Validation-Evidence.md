# P8.1 — POI Preview & Continuity Shell — Validation Evidence

## Baseline

`origin/main` before implementation: `61e24ff30b4c443aa23625ce959d265e89255e66`.
The P8 contract and P7 contract were read-only during this checkpoint. P8.1 uses only
fields already available in the mobile discovery result.

## Current flow audited

- **Selection flow:** `BaseMapPage` renders discovery markers from
  `RouteDiscoveryController.pois`; marker `IconButton` invokes the page-owned modal.
- **POI sheet:** the previous `PoiDetailSheet` was a basic P7 sheet. P8.1 adds
  `PoiPreviewSheet` and does not expand the Detail contract.
- **State ownership:** route planning and discovery remain owned by their existing
  controllers; the page owns modal presentation. Category/reason/distance wording is
  in `poi_presentation.dart`, outside the widget.
- **Route context:** `_routePlanning` and `_routeDiscovery` remain mounted in the same
  `BaseMapPage`; opening/closing the modal does not recalculate route or discovery.

## Implementation

- Added `PoiPreviewSheet` with name, friendly P3 Discovery category, valid distance to
  route, supported reason wording, Cerrar and Ver detalle controls.
- Added reusable presentation mappings for the ten Discovery categories and the two
  supported reason codes. Unknown reason codes are hidden.
- Marker selection now opens Preview. “Ver detalle” closes the Preview and reports that
  the expanded Detail is deferred to P8.2; no P8.1b API data is requested.
- No filters, Map/List synchronization, history, backend, OpenAPI, database, tiles,
  CEFI, or infrastructure changes.
