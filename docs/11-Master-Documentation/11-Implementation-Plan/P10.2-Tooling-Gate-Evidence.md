## Políticas de seguridad y ejecución

- No se imprimen secretos ni valores sensibles en evidencia.
- Un posible secreto real exige sanitización y `STOP_AND_REPORT`.
- Una vulnerabilidad confirmada Critical/High exige `STOP_AND_REPORT`.
- Los findings Medium/Low siguen la política contractual.
- OSV no puede modificar manifests ni lockfiles automáticamente.
- P10.3 podrá obtener las versiones aprobadas mediante un mecanismo reproducible,
  pero no podrá ampliar alcance, introducir permisos, cambiar API/DB/infra ni
  incorporar Java SAST.
