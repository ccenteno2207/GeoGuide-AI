controls and reached `Salir de modo conducción`. The Driving screen exposed the
static summary and exit action; no live GPS, ETA, tracking or navigation controls
were observed. Large text was enabled and the screen remained usable without
visible clipping. TalkBack announced a mixture of Spanish and English labels;
this is recorded as an observation for later UX review, not as a P9 functional
failure.

`P9.3-27` was completed in two controlled attempts. In the first attempt the
operator accidentally accepted **Mientras la app está en uso**; the application
remained open and a real location marker appeared, so the granted path PASSed.

before opening the dialog. The operator selected the exact Android option

new permission. The application UI exposed **Permiso de ubicación bloqueado en
ajustes**. Post-check confirmed both fine and coarse permissions remained
