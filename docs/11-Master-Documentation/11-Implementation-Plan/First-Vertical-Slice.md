# Primer Vertical Slice

El primer objetivo no es construir toda la aplicación.

## Escenario
1. App abre mapa.
2. Obtiene ubicación.
3. Usuario selecciona origen/destino.
4. Backend calcula ruta.
5. Backend consulta POIs cercanos a la ruta.
6. Devuelve 5–20 POIs.
7. Mobile dibuja ruta y marcadores.
8. Usuario abre una ficha.

## Definition of Success
Este flujo funciona de extremo a extremo en un teléfono real usando infraestructura
del piloto.

Todo lo demás se construye encima.
