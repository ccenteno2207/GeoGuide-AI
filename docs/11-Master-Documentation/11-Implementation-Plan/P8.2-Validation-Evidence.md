# P8.2 — POI Detail Experience — Validation Evidence

## Audit and implementation

- Preview: `PoiPreviewSheet`; Detail: `PoiDetailSheet`; navigation remains the existing
  `BaseMapPage` modal ownership.
- `DiscoveryPoi` already carries the P8.1b optional fields: description, sourceLabel,
  sourceUrl and attribution. `poi_presentation.dart` remains the single mapping for
  category, reason and distance wording.
- “Ver detalle” now opens the Detail modal using the selected POI. Closing Detail
  returns to the same `BaseMapPage`; route planning and discovery controllers remain
  mounted, so no route or discovery recalculation occurs.

## Detail behavior

Detail renders the factual name, friendly category, optional description, “A X m del
trazado”, supported reason wording and a neutral reduced provenance section. Source URL
is presented as an accessible selectable source URL without adding a dependency. Missing
optional values omit their sections. UUID, score, raw reason codes, routeProgress,
freshness timestamps and internal provenance metadata are never rendered.
