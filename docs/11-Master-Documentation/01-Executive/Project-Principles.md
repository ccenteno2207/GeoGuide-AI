# Principios Maestros

1. Open Source First.
2. Facts First, AI Second.
3. Map First.
4. Route Discovery es el diferenciador.
5. Seguridad y privacidad por diseño.
6. Modular Monolith antes de microservicios.
7. Docker Compose antes de Kubernetes.
8. PostGIS como fuente geoespacial canónica.
9. Mobile no duplica algoritmos centrales.
10. AI no inventa datos factuales.
11. Expansión por corredores.
12. Medir antes de escalar.
13. ADR para decisiones arquitectónicas.
14. Código probado antes de avanzar.
