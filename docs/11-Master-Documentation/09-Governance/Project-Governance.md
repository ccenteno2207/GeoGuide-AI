# Gobernanza del Proyecto

## Documentación
Todo cambio importante debe actualizar documentación afectada.

## ADR
Crear ADR cuando:
- cambia tecnología central;
- cambia patrón;
- aparece dependencia cloud;
- cambia seguridad;
- se introduce un nuevo datastore;
- se modifica principio arquitectónico.

## Pull Requests
Deben:
- tener alcance claro;
- pasar CI;
- incluir tests;
- actualizar docs;
- evitar secretos.

## Open Source
Antes de publicación pública formal:
- LICENSE;
- CONTRIBUTING;
- CODE_OF_CONDUCT;
- SECURITY;
- política de datos/contribuciones.
