# GeoGuide AI – One Pager

**Discover the journey, not only the destination.**

GeoGuide AI es una plataforma open source de descubrimiento para viajes por carretera.
El usuario define origen y destino; el sistema calcula la ruta y encuentra lugares de
interés relevantes dentro de un corredor razonable.

Casos:
- naturaleza;
- patrimonio;
- arqueología;
- museos;
- miradores;
- gastronomía/servicios futuros.

Modelo:
Free B2C + SaaS territorial + partnerships + marketplace/API futuros.

Estrategia:
validar un corredor real antes de escalar.
