# North Star & KPIs

## North Star candidata
**Meaningful Places Discovered per Active Trip**

No se adopta definitivamente hasta validar que correlaciona con valor para el usuario.

## Funnel
Route planned
→ discovery shown
→ POI preview
→ POI detail
→ visit intent
→ visit/feedback.

## KPIs
- active trips;
- POIs discovered;
- POI open rate;
- discovery-to-interest;
- retention;
- data quality;
- route success;
- API reliability;
- cost per active trip.
