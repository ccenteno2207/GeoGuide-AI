# Riesgos Comerciales

| Riesgo | Impacto | Mitigación |
|---|---|---|
| Datos incorrectos | Alto | provenance + quality |
| Poco interés real | Alto | piloto temprano |
| Competencia grande | Alto | nicho Route Discovery |
| Costos AI | Medio | AI opcional/open source |
| Cobertura insuficiente | Alto | expansión por corredores |
| Monetización invasiva | Alto | reglas comerciales |
| Dependencia de proveedor | Medio | open architecture |
| Escalar demasiado pronto | Alto | gates |
| Contenido/licencias | Alto | governance |
