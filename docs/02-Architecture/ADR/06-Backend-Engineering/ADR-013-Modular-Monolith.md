# ADR-013 – Modular Monolith para el MVP

**Estado:** Aceptado

## Decisión
Construir un monolito modular.

## Razones
- menor complejidad;
- despliegue simple;
- transacciones locales;
- ideal para validar producto;
- módulos pueden extraerse posteriormente.

## Revisión
Reevaluar si aparecen necesidades reales de escalado independiente o ownership separado.
