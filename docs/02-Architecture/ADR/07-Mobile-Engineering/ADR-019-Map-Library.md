# ADR-019 – Librería de mapas

**Estado:** Pendiente de validación técnica final.

## Candidatos
- flutter_map
- MapLibre Flutter

## Selección MVP
La implementación debe realizar un spike breve comparando:
- facilidad de OSM;
- polyline;
- markers;
- clustering;
- offline futuro;
- estabilidad Android/iOS;
- licencia.

No mezclar ambas librerías en la aplicación productiva sin una razón arquitectónica.
