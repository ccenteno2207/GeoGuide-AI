# ADR-016 – Flutter para Mobile

**Estado:** Aceptado

## Decisión
Flutter será el framework móvil inicial.

## Razones
- Android/iOS con base común;
- rendimiento adecuado;
- ecosistema GIS/mapas;
- experiencia consistente;
- productividad para MVP.

## Riesgo
Dependencia de plugins para capacidades nativas.

## Mitigación
Encapsular plugins detrás de interfaces propias.
