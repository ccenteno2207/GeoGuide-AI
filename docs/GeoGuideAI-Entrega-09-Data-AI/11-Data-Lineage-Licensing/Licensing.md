# Licencias y Atribución

Open Source no significa ausencia de obligaciones.

Registrar licencias de:
- datasets;
- mapas;
- imágenes;
- contenido;
- modelos AI;
- librerías.

## OSM
Mantener atribución y revisar obligaciones de ODbL para la forma concreta en que los
datos se utilicen/distribuyan.

## AI
Validar licencia del modelo antes de incorporarlo a una distribución pública.
