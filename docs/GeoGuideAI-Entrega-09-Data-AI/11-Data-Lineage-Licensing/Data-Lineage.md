# Data Lineage

Cada POI debe poder responder:
- ¿de dónde salió?
- ¿cuándo se obtuvo?
- ¿qué transformaciones recibió?
- ¿qué persona/proceso lo validó?
- ¿qué licencia aplica?

## Tablas conceptuales
- source
- ingestion_batch
- source_record
- poi_source_link
- content_version
- quality_assessment
