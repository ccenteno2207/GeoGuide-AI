# Catálogo de Fuentes

## OpenStreetMap
Uso:
- geometría;
- nombres;
- categorías/tags;
- carreteras;
- POIs.

Requiere cumplimiento de atribución y licencia.

## Fuentes públicas oficiales
Potenciales:
- portales gubernamentales de turismo;
- museos;
- áreas naturales;
- patrimonio cultural;
- municipalidades/regiones.

## Datos curados GeoGuide
Carga administrativa validada.

## Contenido generado por IA
Solo como texto derivado/enriquecido y marcado como tal cuando corresponda.

## Regla
No hacer scraping de una fuente sin revisar términos, licencia y estabilidad.
