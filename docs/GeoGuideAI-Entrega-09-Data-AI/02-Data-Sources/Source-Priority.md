# Prioridad de Fuentes

Para datos operativos:
1. fuente oficial del lugar/autoridad;
2. dataset público oficial;
3. dato curado/verificado por GeoGuide;
4. fuente comunitaria con provenance;
5. desconocido/no mostrar.

Para coordenadas:
- fuente geoespacial confiable;
- validación espacial;
- corrección manual auditada.

La IA no ocupa un nivel de autoridad factual.
