# Framework de Calidad

Dimensiones:
- completeness;
- validity;
- accuracy;
- consistency;
- uniqueness;
- freshness;
- provenance.

## Quality Score
Debe ser explicable y basado en reglas.

Ejemplo conceptual:
- coordenadas válidas;
- nombre;
- categoría;
- fuente;
- descripción;
- freshness;
- verificación.

No usar un único score para ocultar qué dimensión falló.
