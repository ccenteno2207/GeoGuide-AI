# Gates de Evolución

## Gate 1 – Technical
Ruta + GPS + POIs + discovery funcionan.

## Gate 2 – Data
POIs suficientemente confiables.

## Gate 3 – UX
Usuarios pueden usar el flujo sin asistencia.

## Gate 4 – Value
Existe evidencia de descubrimiento útil.

## Gate 5 – Retention
Usuarios desean reutilizar el producto.

## Gate 6 – Revenue
Existe señal real de disposición a pagar/partner.

No escalar infraestructura o equipo antes de superar gates relevantes.
