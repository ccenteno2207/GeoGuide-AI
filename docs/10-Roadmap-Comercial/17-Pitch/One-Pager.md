# GeoGuide AI - One Pager

**Discover the journey, not only the destination.**

GeoGuide AI es una plataforma de descubrimiento para viajes por carretera que aplica una estrategia tecnologica Open Source First. La licencia del producto esta en revision; consulte `docs/00-Executive/LICENSING-STATUS.md`.

El usuario define origen y destino; el sistema calcula la ruta y encuentra lugares de interes relevantes dentro de un corredor razonable.

Estrategia: validar un corredor real antes de escalar.
