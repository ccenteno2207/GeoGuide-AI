# Flujos

- Descubrimiento cercano: Inicio → permiso/ubicación → POIs cercanos → ficha.
- Descubrimiento en ruta: Inicio → origen/destino → ruta → POIs → ficha.
- Viaje: ruta activa → Driving/Travel Mode → aviso breve → detalle al detenerse.
- Voz: STT → intención + contexto autorizado → caso de uso GeoGuide → respuesta TTS.
