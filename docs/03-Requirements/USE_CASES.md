# Casos de Uso

UC01 Consultar POIs cercanos a la ubicación autorizada.
UC02 Crear o recibir una ruta.
UC03 Descubrir POIs en el corredor de la ruta.
UC04 Filtrar categorías y ordenar resultados explicables.
UC05 Ver una ficha confiable del POI y sus fuentes.
UC06 Iniciar Driving/Travel Mode y recibir avisos breves.
UC07 Formular una intención por voz y recibir respuesta TTS mediante los mismos casos
de uso disponibles para la interfaz visual.

UC07 no obliga a usar LLM: las intenciones acotadas pueden resolverse de forma
determinista y la IA generativa es un enriquecimiento opcional.
