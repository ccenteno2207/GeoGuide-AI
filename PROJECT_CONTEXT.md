# Project Context

Fase: Foundation

## Propósito

- PostgreSQL + PostGIS
- Redis
- OpenSearch
- OpenStreetMap
- GraphHopper/OSRM
- Docker
- GitHub Actions
- AWS

- Clean Architecture
- DDD
