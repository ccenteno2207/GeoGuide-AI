# GeoGuide AI

## Visión
GeoGuide AI es una plataforma **Open Source** para planificar rutas por carretera enriquecidas con puntos de interés (POI), recomendaciones inteligentes y experiencias de viaje.

## Objetivos
- Plataforma abierta y colaborativa.
- Arquitectura moderna y escalable.
- Uso de OpenStreetMap y tecnologías abiertas.
- IA para recomendaciones personalizadas.
